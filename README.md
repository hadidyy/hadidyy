# Hi, I’m Seif ElHadidy

I’m an Automotive Engineering student at the German International University, interested in the point where mechanical systems, electronics, and control software meet.

My work so far includes embedded control with Arduino, MATLAB/Simulink modeling, power electronics, SolidWorks mechanical design, and engineering simulation.

## Featured projects

| Project | What it demonstrates |
| --- | --- |

## Engineering focus

- **Embedded and power electronics:** Arduino, sensors, PWM, Proteus, DC–DC converters
- **Mechanical design and analysis:** SolidWorks, Fusion 360, ANSYS Fluent, CAD/CAM
