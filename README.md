# Hi, I’m Seif ElHadidy

I’m an Automotive Engineering student at the German International University. I like building complete systems where mechanical design, electronics, perception, and control software meet.

My recent work includes ROS 2 autonomy on NVIDIA Jetson, ESP32 safety firmware, MATLAB control modeling, power electronics, and parametric CAD.
